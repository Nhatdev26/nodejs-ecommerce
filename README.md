# 🛒 Backend API cho Nền tảng Thương mại Điện tử

Thiết kế và triển khai hệ thống backend cho nền tảng thương mại điện tử với các chức năng xác thực người dùng, quản lý sản phẩm và giỏ hàng.  
Áp dụng **kiến trúc MVC** và **mô hình Service Layer** để đảm bảo khả năng mở rộng và bảo trì.  
Tối ưu hóa hiệu suất API bằng **xử lý lỗi bất đồng bộ** và **chuẩn hóa phản hồi**.

## 🛠 Tính Năng Chính

✔ **Quản lý Người dùng**: Đăng ký, Đăng nhập, Đăng xuất, Làm mới token  
✔ **Quản lý Giỏ hàng**: Thêm, Cập nhật, Xóa sản phẩm khỏi giỏ hàng  
✔ **Quản lý Sản phẩm**: CRUD, Tìm kiếm, Kiểm soát hiển thị sản phẩm  
✔ **Bảo mật & Tối ưu hóa**: Xác thực JWT, Kiểm soát truy cập theo vai trò

## 🚀 Công Nghệ Sử Dụng

- **Node.js** & **Express.js** – Framework backend
- **MongoDB** – Cơ sở dữ liệu NoSQL
- **JWT** – Xác thực & Phân quyền
- **Docker** – Đóng gói & Triển khai ứng dụng
